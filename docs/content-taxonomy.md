# Content categories and tags

This is the shared taxonomy for Sisters with Mirrors articles and podcast episodes.

Categories describe the broad subject areas of a piece. Tags describe the specific ideas, experiences, practices or people discussed within it.

## How to use the taxonomy

- Give every article or episode at least one category.
- Usually use one to three categories. Add a fourth only when it is genuinely central to the piece.
- Use specific tags to describe the main topics. Around three to eight tags will suit most content.
- Write category and tag values as lowercase slugs in frontmatter.
- Separate words with hyphens: use `dream-journaling`, not `dream journaling` or `dream_journaling`.
- Reuse an existing tag wherever possible instead of creating a synonym.
- Do not use a category as a tag on the same piece. For example, if `crystals` becomes a category in future, it should not also be applied as a tag.
- Choose taxonomy terms for what the content substantially explores, not ideas mentioned only in passing.

## Suggested taxonomy for a dreams and crystals article

For an article about recent dreams and the way crystals appear to affect them, a strong starting point would be:

```yaml
categories:
  - mystery
  - spirituality
  - energy
tags:
  - dreams
  - dream-recall
  - vivid-dreams
  - crystals
  - crystal-intentions
  - sleep-routine
```

Adjust the tags to match the finished article. For example, add `amethyst` only if amethyst is meaningfully discussed, and use `lucid-dreaming` only if the experience actually involved awareness or control within a dream.

## Adding a new tag

Before adding a tag, ask:

1. Is this idea important to the piece rather than briefly mentioned?
2. Is an existing tag already close enough?
3. Is the wording clear without extra context?
4. Could the tag reasonably be reused on future content?

If the answers support a new tag, add it as a concise lowercase slug and update this document so later articles and episodes can reuse it.
