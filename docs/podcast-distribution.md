# Podcast distribution checklist

The canonical podcast feed is generated by this site from published articles with complete R2 MP3 enclosures:

```text
https://sisterswithmirrors.com/rss.xml
```

Before directory submission, configure the final public R2 media domain, square show artwork, owner name, verification email, author, categories, and explicit-content setting in `src/config/podcast.ts`. Keep each directory show URL blank until registration is complete; do not substitute search pages or guessed destinations.

## Before submitting the feed

- [ ] Replace fixture episodes with real episode metadata.
- [ ] Supply the final podcast show description.
- [ ] Supply podcast author, owner and required contact metadata.
- [ ] Supply the podcast explicit-content setting.
- [ ] Add the final square show artwork.
- [ ] Configure real R2 audio URLs, MIME types and exact byte lengths in published episode frontmatter.
- [ ] Validate the public production feed after deployment.
- [ ] Record each directory's exact show URL above after approval.

Directory policies can change. Review current submission requirements at launch rather than treating this checklist as platform approval.
